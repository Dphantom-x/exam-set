COURSE DESCRIPTION  
This course introduces core data structures and algorithms essential for efficient software development. Students 
will implement and analyze common data structures and algorithmic techniques while solving practical 
programming problems. Topics include line ar and non -linear data structures, searching and sorting algorithms, 
recursion, hash tables, graphs, and algorithm efficiency analysis using Big-O notation. 
TRAINING QUALIFICATIONS  
SET 2430 course focuses on the fundamental concepts and techniques required to design, analyze, and implement 
efficient data structures and algorithms. Students learn how data is organized, stored, and manipulated to solve 
computational problems effectively. The course introduces core data structures and algorithmic strategies through 
problem-solving, code implementation, and performance analysis. By the end of the course, students demonstrate 
their ability to select appropriate data structures and algorithms, imple ment them in code, and evaluate their 
efficiency using standard analytical methods. 
 
  By the end of this course, students will be able to: 
• Explain the purpose and characteristics of fundamental data structures, including arrays, linked lists, stacks, 
queues, trees, hash tables, and graphs. 
• Implement common data structures and algorithms using a programming language to solve practical 
programming problems. 
• Analyze algorithm efficiency using time and space complexity concepts, including Big-O notation. 
• Select appropriate data structures and algorithms based on problem requirements and performance 
constraints. 
• Apply algorithmic techniques such as recursion, searching, sorting, and traversal. 
• Debug, test, and optimize algorithm implementations to improve correctness and efficiency. 
• Decompose complex problems into manageable components and develop logical, step-by-step solutions. 
• Communicate algorithmic ideas clearly and demonstrate critical thinking, persistence, and initiative while 
working independently or collaboratively.

COURSE OUTLINE   
Topics 
Week 1 Topic: Introduction & Python Refresher 
Week 1: Wednesday (Sep 2), Thursday (Sep 3) in person class 
 
In this session, students will learn the role of data structures and algorithms in software development: 
 
• Understand the course scope, expectations, and the importance of data structures and algorithms. 
• Review Python syntax, variables, control flow, functions, and basic data types. 
• Set up a development environment and practice simple Python exercises. 
• Introduce Abstract Data Types (ADTs) and basic data structures, understanding the difference between 
what operations a structure supports (ADT) and how it is implemented (implementation). 
 
Class Assignment 1 
 
Week 2 Topic: Python Programming Fundamentals & OOP 
Week 2: Wednesday (Sep 9), Thursday (Sep 10) 
 
In the second week, students will: 
 
• Review Python syntax and write Python functions, understanding parameters, return values, and 
basic scope rules. 
• Explore Python collections: lists, tuples, dictionaries, and sets. 
• Learn Object-Oriented Programming (OOP) in Python: classes and objects, attributes and methods, 
constructors (__init__), Basic inheritance 
• Practice reading, writing, and debugging Python code, including simple OOP examples 
• Emphasize clean syntax, readability, and Pythonic conventions. 
• Compare Python syntax with Java, including: Indentation vs. braces for code blocks; Dynamic vs. static typing; Lists 
vs. arrays; Dictionaries vs. Java Map 
 
Class Assignment 2 
 
Week 3 Topic: Mathematical & Algorithm Foundations 
Week 3: Wednesday (Sep 16), Thursday (Sep 17) in person class 
 
Learning Objectives: 
• Introduce essential mathematical tools for algorithm analysis, including sets, relations, common mathematical 
notations, summations, and logarithms. 
• Understand recurrence relations and how they describe the performance of recursive algorithms. 
• Learn basic proof techniques for validating algorithm correctness. 
• Gain an initial understanding of estimation and approximation for algorithm efficiency. 
 
Class Assignment 3 
 
 
Week 4  Topic: Algorithm Analysis (Part 1) 
Week 4: Wednesday (Sep 23), Thursday (Sep 24) 
 
• Learning Objectives: 
• Understand the relationship between problems, algorithms, and programs. 
• Compare algorithms and analyze their best, worst, and average-case performance. 
• Learn asymptotic analysis (Big-O notation) to evaluate algorithm efficiency. 
• Discuss the impact of algorithm efficiency versus hardware performance on program execution. 
 
Class Assignment 4

Week 5 Topic:  Algorithm Analysis (Part 2) 
Week 5: Wednesday (Sep 30), Thursday (Oct 1) 
 
• Learning Objectives: 
• Understand lower bounds and Θ (Theta) notation for analyzing algorithm performance. 
• Calculate program running time and analyze algorithms with multiple input parameters. 
• Introduce space complexity and strategies for efficient code design and tuning. 
• Practice empirical analysis of algorithms using examples to measure performance.

Week 6 Topic: Linear Structures: Arrays, Lists 
Week 6: Wednesday (Oct 7), Thursday (Oct 8) 
 
Learning Objectives: 
• Understand the List Abstract Data Type (ADT) and its core operations. 
• Implement array-based lists and linked lists in Python. 
• Analyze and compare performance trade-offs between arrays, linked lists, stacks, and queues. 
• Solve practical problems using linear data structures. 
 
Class Assignment 6 
Week 7 Topic: Linear Structures: Stacks and Queues 
Week 7: Wednesday (Oct 14), Thursday (Oct 15) in person class 
 
Learning Objectives: 
• Understand stack and queue ADTs and implement them using arrays or linked lists. 
• Apply stacks and queues to practical problems, such as expression evaluation and task scheduling. 
• Explore priority queues and understand their use cases in real-world applications. 
• Analyze and compare performance trade-offs for stacks, queues, and priority queues 
Project

Midterm 
 
Week 9 Topic : Design Patterns & Dictionaries  
Week 9: Wednesday (Oct 28), Thursday (Oct 29) 
 
Learning Objectives: 
• Understand design patterns for data structures and their application in Python. 
• Compare alternative list designs and explore trade-offs in different implementations. 
• Learn the Dictionary Abstract Data Type (ADT) and its core operations. 
• Implement dictionary-like structures using Python and apply them to practical problems.

• Introduction to binary trees as a recursive data structure.

Week 12: Wednesday (Nov 18), Thursday (Nov 19) 
Learning Objectives: 
• Introduce sorting terminology and notation (stability, in-place, comparisons). 
• Analyze the cost of sorting algorithms using time complexity. 
• Implement insertion sort and exchange-based sorting in Python. 
• Understand why simple sorting algorithms perform well on small or nearly sorted datasets.

Week 14 Topic: Sorting Algorithms (Part 2: Efficient & Advanced Methods) 
Week 14: Wednesday (Dec 2), Thursday ( Dec 3) 
Learning Objectives: 
• Understand divide-and-conquer strategies in sorting. 
• Implement merge sort and quick sort and analyze their performance trade-offs.

Class Assignment 10 
Week 15: Topic: Hashing  
Week 15: Wednesday (Dec 9), Thursday ( Dec 10) in person class 
    Learning Objectives: 
• Introduce hashing concepts and the motivation for using hash tables. 
• Understand hash function principles and characteristics of good hash functions. 
• Implement hash tables in Python using basic hash functions. 
• Handle collisions using common strategies (e.g., chaining, open addressing). 
• Apply hashing for efficient data storage, lookup, and retrieval. 
• Analyze the average-case performance of hashing operations. 
                               Graphs   
• Introduce graph terminology and common graph representations (adjacency list, adjacency matrix). 
• Implement graph data structures in Python. 
• Implement and apply graph traversal algorithms: Depth-First Search (DFS) and Breadth-First Search (BFS). 
• Understand and apply topological sorting for dependency-based problems. 
• Introduce shortest path and minimum spanning tree problems at a conceptual and implementation level. 
• Analyze the time and space complexity of common graph algorithms.
