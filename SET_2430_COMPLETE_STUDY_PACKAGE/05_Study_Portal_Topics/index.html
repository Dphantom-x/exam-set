Big-O Time Complexity Compass

Ranked from best to worst asymptotic runtime growth rate.

O(1)
Constant Time

Dictionary lookup, list index access, append to end.

O(log n)
Logarithmic Time

Binary search, balanced BST search.

O(n)
Linear Time

Single for-loop over list, linear search.

O(n log n)
Linearithmic Time

Merge Sort, Timsort (Python sorted()), Heap Sort.

O(n²)
Quadratic Time

Nested loops, Bubble Sort, Selection Sort, Insertion Sort.

O(2ⁿ)
Exponential Time

Naive recursive Fibonacci, generating all subsets.
