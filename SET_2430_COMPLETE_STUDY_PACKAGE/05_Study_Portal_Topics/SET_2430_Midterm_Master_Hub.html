🛡️ The No-IDE Paper-Based Exam Survival Protocol

On paper, you have no compiler, no auto-complete, no terminal tracebacks, and no syntax highlighting. Prof. Xiao and CUNY graders deduct 30% to 50% of credit for missing colons, pointer amnesia, and loop boundary mistakes. Memorize these defensive handwriting rules before tomorrow morning:

1. The "Save Before You Sever" Rule

Never rewire curr.next = new_node without first saving your only link downstream:

# CORRECT ORDER ON PAPER:
next_node = curr.next      # 1. Anchor downstream
curr.next = new_node       # 2. Break upstream
new_node.next = next_node  # 3. Link back
2. The 4 Mandatory Linked List Edge Cases

Every single handwritten linked list method must guard these 4 conditions:

  • Empty List: if not self.head: return False
  • Single-Node List: if self.head.right is None: self.head = None
  • Head Deletion: self.head = self.head.right (+ rewire tail in circular)
  • Target Missing: Loop terminates safely without accessing None.right!
3. The Circular List Loop Guard

Writing while curr is not None: on a Circular Linked List will loop infinitely and cost full credit!

# CORRECT CIRCULAR SCAN:
curr = self.head
while curr.right != self.head:
    curr = curr.right  # Stops cleanly at TAIL!
4. 10-Minute Pre-Submission Paper Audit
  • ✓ Did every method include self in its argument list?
  • ✓ Did every if, else, while, for, def, class end with a colon :?
  • ✓ Did you update self.size += 1 on insert and self.size -= 1 on delete?
  • ✓ Are indentation levels cleanly drawn with 3-character distinct spacing?
