Recursion, Call Stacks & Recurrence

Every recursive call consumes stack frames in memory. Understanding the base condition, the recursive step, and measuring call tree depth is fundamental to preventing stack overflow and analyzing algorithmic efficiency.

1. Golden Rules of Recursion

  • • Base Case: Must have at least one terminal condition that halts without making further recursive calls.
  • • Progress: Each recursive call must reduce the problem size toward the base case.
  • • Call Stack Cost: Each call pushes arguments, return address, and local variables onto the call stack.

2. Recurrence Relations

  • • Linear Recursion: T(n) = T(n-1) + O(1) ⟹ O(n)
  • • Divide & Conquer: T(n) = 2T(n/2) + O(n) ⟹ O(n log n) (Merge Sort)
  • • Branching (Naive Fib): T(n) = T(n-1) + T(n-2) + O(1) ⟹ O(2ⁿ)
